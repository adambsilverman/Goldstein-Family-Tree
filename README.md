# Goldstein Family Tree

An interactive, shareable family tree. Family members open it from a link or QR code, find themselves,
and add birth and death dates, places, photos, stories, marriages and children. Everyone sees changes live.

Views: tree chart · fan chart · one family at a time · list · "How are we related?" · timeline · fill in the gaps.
Exports: backup (.json), GEDCOM (.ged) for Ancestry/FamilySearch/MyHeritage, poster-size chart (.svg).

The family's data is not in this repository. It is kept in a private shared database that only people
with the family link can open.
